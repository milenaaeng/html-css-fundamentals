# html-css-fundamentals
Repositório criado para registrar meus estudos e exercícios práticos de HTML e CSS, explorando conceitos fundamentais de desenvolvimento front-end

# 🎯 objetivo
Praticar conceitos de HTML e CSS através de pequenos exercícios,
explorando diferentes técnicas de estruturação, estilização,
layouts e responsividade

# 🧠 aprendizados

Este repositório serve como registro da minha evolução
durante os estudos de desenvolvimento front-end

Busco entender o funcionamento dos conceitos e o motivo de cada
propriedade utilizada, e não apenas reproduzir códigos
